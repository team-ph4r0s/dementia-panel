# VLESS + Reality

Второй протокол панели, кроме AmneziaWG: **VLESS + Reality** на ядре **Xray-core**. Reality маскирует подключение под обычный
TLS 1.3 к чужому сайту, поэтому домен и сертификат не нужны. Устроен так же, как AWG: нода в Docker по SSH без агента, конфиг
ноды целиком из БД, все операции — через очередь `runExclusive`, трафик дельтами, автообновляемые подписки.

## Когда выбирать VLESS

- AmneziaWG (UDP) блокируется или режется в сети пользователя, а TCP 443 проходит;
- нужен трафик, неотличимый от HTTPS к популярному сайту.

AmneziaWG быстрее на чистом UDP и остаётся протоколом по умолчанию.

## Модель данных (контракт)

Протокол — поле `servers.protocol` (`awg` | `vless`, миграция v15); код — `utils/vless-params.ts`, `services/xray.service.ts`.

| Что | Где |
|---|---|
| Порт (TCP) | `awg_port`, применённый — `deployed_port` (как у AWG) |
| Ключи Reality x25519 | `server_private_key` / `server_public_key` в base64; в config.json и ссылках — base64url (`toXrayKey`) |
| Параметры | `reality_sni`, `reality_dest` (`домен:порт`), `reality_short_ids` (JSON), `xray_flow`, `xray_fingerprint`; проверка — `validateVlessParams` |
| Клиент | `client_uuid` (секрет, как приватный ключ: не отдаётся в API и гостю); `client_ip`, ключи — пустые строки |
| Контейнер | `dementia-xray`, конфиг `/opt/dementia-xray/config.json`, образ `ghcr.io/xtls/xray-core:latest` |

Один сервер в панели — один протокол. Чтобы держать оба на одном хосте, добавьте его дважды с разными портами
(AWG — UDP, VLESS — TCP; совпадение номера порта между протоколами допустимо).

## Добавление ноды

В окне «Добавить сервер» выберите **VLESS Reality**: порт по умолчанию 443 (должен быть свободен), подсети нет. Панель генерирует
ключи и параметры Reality (`generateVlessParams`: сайт из списка `DEFAULT_REALITY_TARGETS` — без `www.microsoft.com`/`www.apple.com`, на которые Xray 26 предупреждает о блокировке, один shortId, flow `xtls-rprx-vision`,
отпечаток `chrome`). Установка — `deploy-xray.sh` через stdin, см. [node-management.md](node-management.md#vless).

## Параметры Reality

- **SNI** — имя сайта, под который маскируется подключение; **адрес маскировки** — куда Xray отдаёт чужие подключения (`домен:443`).
- **shortId** — 1–8 hex-строк чётной длины до 16 символов; клиенту выдаётся первый.
- **flow** — `xtls-rprx-vision` (или пусто), **отпечаток TLS** — `chrome`, `firefox`, `safari`, `ios`, `android`, `edge`, `random`, `randomized`.

Сайт для маскировки: TLS 1.3 и HTTP/2, не за Cloudflare, желательно в той же сети/стране, что и нода, и доступный из страны
пользователей. Смена параметров перезапускает контейнер (`requestApply`, откат как у AWG — инвариант 28); пользователям нужно
обновить подписку. Действия AWG («Перейти на 3.x», «Сканировать», импорт Amnezia) для VLESS возвращают 400.

## Клиенты и подписки

Ссылка клиента — `vless://<uuid>@<host>:<port>?type=tcp&security=reality&pbk=…&fp=…&sni=…&sid=…&flow=…&encryption=none#<имя>`;
её отдают «Конфиг» (`.txt`), QR и подписка. Форматы подписки — [subscriptions.md](subscriptions.md).

## Синхронизация и трафик

- Добавление/удаление клиентов (`requestSync`) перезаписывает config.json и перезапускает контейнер: соединения переподключаются
  за секунды. Переход на `xray api adu/rmu` без перезапуска — следующий шаг.
- Смена параметров Reality — перезапуск контейнера; смена порта — переустановка.
- Трафик — `statsquery -reset` по пользователям `c<id клиента>`, копится в `total_rx`/`total_tx` (как у AWG, инвариант 14).

## Мосты

Мост пересылает ноду VLESS одним правилом TCP `мост:listen_port` → `нода:awg_port` ([bridges.md](bridges.md)). Сквозной проверки
через заглушку у VLESS нет, поэтому мост выдаётся в режиме `always` или в `auto` при `active`.

## Ограничения первой версии

- VLESS-ноды нельзя передавать партнёрам (`/api/partners` и федерация отвечают 400, в `/nodes` их нет): UUID — общий секрет,
  передачу между панелями нужно проектировать отдельно.
- Нет импорта Xray-серверов из приложения AmneziaVPN, автообновления образа Xray и проверки доступности из стран.

## Частые проблемы

- **Порт 443 занят** (nginx, другой прокси) — освободите порт или выберите другой.
- **Время на устройстве** — Reality отклоняет клиентов с расхождением часов больше ~90 секунд.
- **Сайт маскировки недоступен или заблокирован** в стране пользователя — подключения не устанавливаются; выберите другой.
