# Data City и вид «Город» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** заменить тему Topology темой Data City и добавить в раздел «Ноды» 3D-вид «Город».

**Architecture:** план города — чистая функция `buildCity` поверх `buildTopology`; отрисовка — императивный модуль на Three.js
(`city/scene.ts`), React-обёртка `TopologyCity` грузится лениво. Тема меняется значениями токенов в `index.css` без правки компонентов.

**Tech Stack:** React 19, Vite, Tailwind 4, TypeScript, Three.js, vitest + Testing Library (jsdom).

**Spec:** [docs/superpowers/specs/2026-11-11-data-city-design.md](../specs/2026-11-11-data-city-design.md)

## Global Constraints

- Ничего не грузится извне: шрифты — `@fontsource/*`, Three.js — из npm в ленивом чанке (инвариант 35).
- Имена токенов в `index.css` не меняются; цвета в компонентах — только токены.
- Тексты интерфейса — на русском; размер текста не меньше `text-xs`.
- Карта строится из уже имеющихся данных и не ходит на сервер (инвариант 43); раскладка города проверяется тестом.
- Сервис-воркер: логику кеша не трогать (инвариант 44).
- Версия `0.2.42`, раздел `## v0.2.42 — 2026-11-11` в `CHANGELOG.md`.

## Review Focus

- Пустая сеть (ни одной ноды): город показывает только штаб, без ошибок — тест в Task 1.
- Нода без клиентов (`client_count = 0`): высота минимальная, окна не горят, деления на ноль нет — тест в Task 1.
- Много нод (40): участки не пересекаются, всё влезает — тест в Task 1.
- Браузер без WebGL: сообщение и кнопка «Открыть карту», не падение — тест в Task 2.
- Выбранная нода удалена при открытом «Городе»: инспектор показывает сводку (уже обеспечивает `valid` в `ServersView`) — тест в Task 3.

### Task 1: План города `buildCity`

**Files:** Create `client/src/topology/city.ts`, `client/src/topology/city.test.ts`

**Interfaces — Produces:**
```ts
export interface CityLot { key: string; kind: TopoKind; id: number | string; label: string; sub: string; health: Health;
  x: number; z: number; w: number; d: number; h: number; lit: number; flags: TopoNode['flags'] }
export interface CityRoad { key: string; kind: EdgeKind; from: string; to: string; health: Health; flow: boolean;
  weight: number; elevated: boolean; points: [number, number][] }
export interface CityPlan { lots: CityLot[]; roads: CityRoad[]; size: number }
export function buildCity(topology: Topology, servers: Pick<Server, 'id' | 'client_count' | 'active_client_count'>[]): CityPlan
```
Раскладка: штаб в центре; ноды, мосты и страны — на трёх кольцах сетки кварталов (шаг `BLOCK = 6`), угол — `node.angle`,
при занятом месте берётся ближайший свободный по кольцу. Высота ноды `7 + min(client_count, 80) * 0.38`, мост `5`, страна `1`, штаб `16`.
`lit = active / client_count` (0 при 0). Рёбра `bridge-server` — `elevated: true`. `size` — сторона квадрата, вмещающего все участки.

- [ ] Тесты: `один участок на узел`, `участки не пересекаются (40 нод, 6 мостов, 10 стран)`, `сторона совпадает со знаком cos/sin angle`,
  `высота монотонна по client_count`, `пустая сеть — только штаб`, `client_count 0 → lit 0`, `flow копируется из ребра`, `детерминирован`.
- [ ] `npx vitest run src/topology/city.test.ts` → FAIL; реализовать; → PASS. Коммит.

### Task 2: Сцена и `TopologyCity`

**Files:** Create `client/src/city/scene.ts`, `client/src/components/TopologyCity.tsx`, `client/src/components/TopologyCity.test.tsx`; Modify `client/package.json` (`three`, `@types/three`).

**Interfaces — Consumes:** `buildCity`, `CityPlan`. **Produces:**
```ts
export interface CityScene { update(plan: CityPlan): void; setSelected(key: string | null): void; setHover(key: string | null): void;
  pick(clientX: number, clientY: number): string | null; project(key: string): { x: number; y: number; visible: boolean } | null; dispose(): void }
export function webglAvailable(): boolean
export function createCityScene(canvas: HTMLCanvasElement, opts: { reducedMotion: boolean; colors: CityColors }): CityScene
export function TopologyCity(props: { servers; bridges; subscribers; selected: Selection | null; onSelect(next: Selection | null): void; onOpenMap(): void })
```
Цвета сцены читаются из CSS-переменных (`getComputedStyle`) — тема одна, но значения не дублируются.
Фоновая застройка — `InstancedMesh`; цикл останавливается при `document.hidden` и вне экрана (`IntersectionObserver`); `setPixelRatio(min(dpr, 1.5))`.

- [ ] Тесты (jsdom без WebGL): `без WebGL — сообщение «3D недоступно в этом браузере» и кнопка «Открыть карту» вызывает onOpenMap`;
  `подписи — кнопки с именем ноды; клик вызывает onSelect({kind:'server', id})` (подписи рендерятся и без WebGL — список под сообщением).
- [ ] FAIL → реализация → PASS. Коммит.
