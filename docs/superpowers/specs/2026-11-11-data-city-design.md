# Оформление Data City и 3D-вид «Город» — дизайн

Дата: 2026-11-11 · Версия после реализации: **v0.2.42**

## Цель

Владелец выбрал концепцию Data City (макет `design-concepts/3d/07-city.html`) как новое оформление панели. Нужно:

1. **Полностью заменить тему Topology темой Data City** во всём клиенте. Переключателя тем нет — одна тема, как при переходе Bento → Topology в v0.2.9.
2. **Добавить в раздел «Ноды» четвёртый вид «Город»** рядом с «Картой», «Глобусом» и «Списком»: 3D-город на настоящих данных, где ноды — небоскрёбы.

Раскладка экранов, компоненты, тексты и поведение панели не меняются: это смена оформления и один новый вид.

## Решения

| Вопрос | Решение |
|---|---|
| Что берём из макета | Тему для всей панели и город как новый вид |
| Тема | Заменяет Topology полностью, без переключателя |
| 3D | Чистый Three.js в отдельном модуле (не React Three Fiber, не CSS 3D) |
| Источник данных города | Та же модель `buildTopology` (topology/model.ts), что у карты и глобуса |
| Вид по умолчанию | Не меняется: на компьютере — «Карта», на узком экране — «Список» |

## Часть 1. Вид «Город»

### Что есть что

- **Панель** — центральная башня-штаб с прожектором; есть всегда.
- **Нода** (`kind: 'server'`) — небоскрёб вокруг штаба. Сторона города совпадает со стороной ноды на 2D-карте (берётся `angle` узла модели).
  - Высота растёт с `client_count` (монотонно, с ограничением сверху).
  - Доля горящих окон = `active_client_count / client_count` (0 для ноды без клиентов).
  - Цвет рёбер и маяка — по `health`: `ok` → `ok` (циан), `warn` → `warn` (оранжевый), `fail` → `bad` (маджента), `idle` → `faint` (серый).
  - Флаги узла: `partner` — другая крыша (антенна-тарелка); `sync` — мигающий маяк; `outdated` — значок в подписи.
- **Мост** (`kind: 'bridge'`) — фиолетовое (`violet`) здание пониже на внешнем кольце. Рёбра `bridge-server` — надземные переходы к башням нод: `flow` — светится и по нему бегут пакеты, иначе тусклый.
- **Страна** (`kind: 'country'`) — въезд на краю города: флаг и число пользователей из `sub`. Рёбра `country-*` — дороги к мосту или ноде.
- **Трафик** — машины только на рёбрах с `flow = true`; плотность пропорциональна `weight`.
- **Фоновая застройка** — тёмные кварталы для антуража, одна `InstancedMesh`; не кликается.

### Взаимодействие

- Клик/тап по зданию или въезду → `onSelect(Selection)` — тот же инспектор справа, что у карты и глобуса; Esc снимает выбор (уже есть в `ServersView`).
- Наведение подсвечивает соседей (`neighbours()` из модели) и приглушает остальное.
- Над зданиями — HTML-подписи «имя · клиенты». **Подписи — кнопки** (`<button>`): город проходится с клавиатуры (Tab, Enter) и тестируется без WebGL.
- Камера: вращение перетаскиванием, приближение колесом/щипком в пределах (не уходит под землю и не улетает); пока пользователь не трогает сцену — медленный облёт. При `prefers-reduced-motion` облёта и машин нет, маяки не мигают.

### Производительность и устройства

- Цикл анимации останавливается, когда вкладка скрыта или холст вне экрана (`IntersectionObserver`); при размонтировании — `dispose()` геометрий, материалов, текстур и рендерера.
- `devicePixelRatio` ограничен 1.5.
- Без WebGL (контекст не создаётся) — сообщение «3D недоступно в этом браузере» и кнопка «Открыть карту».
- Живые обновления: новый план после изменения данных применяется `update(plan)` — пересоздаются изменившиеся здания, камера остаётся на месте.

## Часть 2. Тема Data City

### Палитра

Имена токенов в `client/src/index.css` не меняются — меняются значения, поэтому компоненты (≈ 860 мест с токенами) не переписываются.

| Токен | Значение |
|---|---|
| `page` / `paper` / `card` | `#07060d` / `#0b0a14` / `#0e0c1a` |
| `soft` / `soft-2` / `line` | `#161329` / `#211c3d` / `#2a2446` |
| `ink` / `muted` / `faint` | `#f1f0ff` / `#a29dbf` / `#6f6a8c` |
| `on-accent` | `#0a0900` |
| `brand` (главное действие, выбранное) | `#fcee0a` (жёлтый) |
| `ok` (в сети, успех) | `#00e5ff` (циан) |
| `warn` / `orange` (внимание) | `#ff9f1c` (оранжевый) |
| `bad` / `danger` / `pink` (сбой) | `#ff2e88` (маджента) |
| `violet` / `accent` (мосты) | `#a78bfa` |
| `blue` / `info` | `#7aa2ff` |
| `*-soft` | те же цвета с прозрачностью 0.10–0.14 |

Предупреждение — оранжевое, а не жёлтое, как в макете: жёлтый занят главным действием. Контраст `muted` и `faint` на `card` проверяется: `muted` ≥ 4.5:1 (текст), `faint` ≥ 3:1 (подписи и плейсхолдеры; если меньше — значение поднимается).

### Шрифты

Все из сборки (`@fontsource/*`), ничего извне (инвариант 35):

- **Unbounded** (`--font-display`) — заголовки, логотип, крупные числа сводок, главные кнопки.
- **JetBrains Mono** (`--font-mono`) — данные: хосты, IP, ключи, счётчики. Заменяет IBM Plex Mono (пакет `@fontsource/ibm-plex-mono` удаляется).
- **Onest** (`--font-sans`) — обычный текст, как сейчас.
- Шрифт флагов Twemoji Country Flags остаётся первым в каждом стеке.

### Формы и детали

- Скругления уменьшаются (`--radius-*`): HUD-острые углы.
- Класс `hud-cut`: срезанные правый верхний и левый нижний углы (`clip-path`) с маленьким жёлтым уголком на срезе (псевдоэлемент — он же скрывает разрыв рамки). Получают: `ModalShell`, основные карточки разделов, главные кнопки. Поля ввода, бейджи и мелкие кнопки — без среза.
- Шапка (`Navbar`): жёлтая плашка-логотип со скосом, жёлтая линия снизу, у активного раздела жёлтое подчёркивание; боковое меню на телефоне — в том же стиле.
- Фон: вместо точечной сетки — едва заметная сетка линий («план города»). Градиентов в элементах интерфейса нет.
- Экран входа (`LoginView`), `public/manifest.webmanifest` (`theme_color`, `background_color`), `public/favicon.svg`, иконки (`scripts/make-icons.cjs`) — в цветах новой темы; `BrandMark` сохраняет форму.
- Два захардкоженных цвета в `SubscriptionModal.tsx` заменяются на новые значения или токены. Упоминание цвета в `public/sw.js` правится, логика кеша не трогается (инвариант 44).

## Часть 3. Код, тесты, документация

### Модули

| Файл | Ответственность |
|---|---|
| `client/src/topology/city.ts` | Чистая функция `buildCity(topology: Topology): CityPlan` — участки (`key`, `kind`, позиция, размеры, высота, `health`, доля окон, флаги, подпись), дороги, переходы, въезды. Без React и Three.js. |
| `client/src/city/scene.ts` | Отрисовка на Three.js: `createCityScene(canvas, opts)` → `{ update(plan), setSelected(key), setHover(key), pick(x, y): string \| null, dispose() }`. Решений о данных не принимает. |
| `client/src/components/TopologyCity.tsx` | React-обёртка: холст, подписи-кнопки, сообщение без WebGL; `lazy()`-импорт в `ServersView`, как у глобуса. |
| `client/src/components/ServersView.tsx` | `ViewMode` += `'city'`; переключатель (иконка `Building2`), `readMode` принимает `'city'`. |

Зависимости клиента: `three`, `@types/three` (dev). Three.js попадает только в ленивый чанк вида «Город».

### Тесты

- `topology/city.test.ts`: у каждой ноды, моста и страны ровно один участок; участки не пересекаются; нода стоит с той же стороны, что на карте; высота монотонна по `client_count`; машины/частицы только на рёбрах с `flow`; план детерминирован.
- `components/TopologyCity.test.tsx`: в jsdom (без WebGL) — сообщение и кнопка «Открыть карту»; нажатие на подпись вызывает `onSelect` с нужным `Selection`.
- `components/ServersView.test.tsx`: переключение на «Город»; сохранённый режим `'city'` восстанавливается.
- Полный прогон: `client` — `tsc -b`, `lint`, `test`, `vite build` (CI проверяет CSS сборки на внешние URL); `server` — `tsc --noEmit`, `npm test` (сервер не меняется, прогон для чек-листа).
- Живая проверка в превью (`panel-api` + `panel-ui`): ширина компьютера и телефона, все разделы в новой теме, вид «Город», без ошибок в консоли; скриншоты.

### Документация и версия

- `AGENTS.md`: абзац об оформлении — Data City вместо Topology; правило «циан — это `ok` (в сети), жёлтый `brand` — главное действие, оранжевый `warn` — внимание»; структура — `client/src/city/`; инвариант 43 — город строится из той же модели, сам на сервер не ходит, раскладка проверяется тестом.
- `docs/architecture.md`, `docs/pwa.md` — по затронутым местам (вид «Город», цвета манифеста).
- Корневой `package.json` → `0.2.42`; раздел `## v0.2.42 — дата` в `CHANGELOG.md` (новая функция и смена оформления — цифра Z).

## Вне рамок

- Переключатель тем, светлая тема.
- Изменение раскладки экранов, текстов, API, сервера и базы данных.
- Замена или удаление 2D-карты и глобуса.
- Город для нод партнёров с особой логикой сверх флага `partner`.
